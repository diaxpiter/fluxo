# Financial App

A personal finance app focused on **cash-flow planning**: see what's already spoken for (fixed bills, savings, investments, shared expenses) the moment income lands, so what's left to spend is obvious before the month gets away from you.

Not a fixed-category budgeting app — an onboarding questionnaire adapts the app's accounts and rules to each person's actual financial structure (fixed salary vs. irregular freelance income, different savings/investing priorities, etc.).

## Stack

- [Next.js](https://nextjs.org) (App Router) + TypeScript + Tailwind CSS
- [Supabase](https://supabase.com) (Postgres + Auth + Row Level Security)
- Deployed on [Vercel](https://vercel.com), installable as a PWA

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
